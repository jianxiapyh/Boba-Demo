On-site quick guide

Boba Immersive Demo

Launch ALVR, connect the Quest, then choose the mesh-based Lab or Gaussian Ambulance scene.

Offline page Lab + Ambulance One-click command copy

1Start ALVR first

Open Terminal 1, copy this block, paste it, and press Enter:

Terminal 1 · ALVR 
cd /home/yihan/Downloads/alvr_streamer_linux/bin
./alvr_dashboard
  1. Put the computer and Quest on Emacs, the default demo network.
  2. Start SteamVR, then open ALVR on the Quest.
  3. Choose Trust in the desktop dashboard.
  4. Confirm SteamVR sees the headset and both controllers.

Using a network other than Emacs?

First compare the connection values below with the Hostname and IP address shown inside ALVR on the Quest.

Current hostname7921.client
Current IP address10.200.15.239
  1. Connect the computer and Quest to the same low-latency network.
  2. In the desktop dashboard, open Devices → Edit connection.
  3. Replace both fields with the exact values displayed inside the Quest.
  4. Use Add new only to keep another known IP, then choose Save and Trust.

Important: enter the Quest values, not the computer hostname or IP.

2Prepare for alignment

  • Computer is on power
  • Quest and controller batteries are ready
  • Wearer is standing with the Quest on and upright
  • Wearer is looking naturally forward
Do not launch with the headset on a desk. Startup captures its position and direction.

The launcher uses an explicit standing layout; automatic posture detection is not enabled. Add --immersive_start_posture seated only for a seated test.

Ambulance · Gaussian scene

Clear-aisle view facing Rope on the stretcher. Standing eye height is 1.45 m above the floor with a 30° downward view. Rope and Sloth are both free play.

Terminal 2 · Ambulance 
source /home/yihan/miniconda3/etc/profile.d/conda.sh

The launcher selects phystwin-cu132 automatically. To change scenes, stop and relaunch. Rope and Sloth can be switched without restarting.

4Finish startup

  1. Press either trigger once for each tutorial page.
  2. On the last page, wait for Ready, release the trigger, then press it once.
  3. Check that Rope and the chosen scene appear in the headset.
  4. Check both controller rays and test one grab and release.
  5. Check that the desktop window shows the scene, object, rays, and headset.

The first launch can pause while CUDA or the OpenXR bridge compiles. Keep the terminal open while it continues printing output.

Headset controls

ControlAction
TriggerAdvance tutorial; hold to grab, release to drop
Point at markerSelect that interaction point automatically
X or AOptionally cycle interaction points
Y or B · shortRestart Lab Rope or reset the current free-play object
Y or B · hold 0.75 sOpen the Rope/Sloth selector
Joystick up/downMove one selector row; recenter before moving again
Trigger in selectorConfirm highlighted object
Y or B in selectorCancel selector
Grip · holdExit demo

Wait for the loading overlay when switching Rope or Sloth. Do not press the selection buttons repeatedly.

Reset or stop

  • Between attendees, short-press Y or B. In Ambulance, this returns the object to the stretcher.
  • If a new wearer has a badly tilted view, relaunch while they wear the upright headset and look forward.
  • To stop normally, press Ctrl+C in Terminal 2. Holding either Grip also exits.

Quick troubleshooting

Headset or controllers are not detected

Stop the demo. Confirm ALVR is open on the Quest, the dashboard trusts it, and SteamVR shows the headset and both controllers. Then relaunch.

Initial view is tilted or displaced

Stop, recenter SteamVR/ALVR if needed, and relaunch with the headset worn upright while the wearer looks forward.

Final tutorial page does not continue

Wait for Ready, fully release the trigger, and press it once.

Object switching appears frozen

Wait for the progress overlay. If the terminal reports an error or stops progressing, press Ctrl+C, verify SteamVR remains connected, and relaunch the same scene.
