On-Site Launch Guide

Exact, copy-ready commands for the double_stretch_sloth demo. This page is fully local and works without Internet access.

Mode 1 Travel router

No venue Internet required. Attendees join the Emacs Wi-Fi.

 Mode 2 Cloudflare

The computer needs Internet. Attendees keep their current connection.

Before opening the venue

  • Connect the demo computer to its monitor, keyboard, mouse, and power.
  • Have one phone ready for a complete test.
  • For Mode 1, bring the travel router, its power supply, and an Ethernet cable.
  • Phone video adapts automatically; do not add a phone-FPS flag to the commands.
No Internet required

Mode 1: Travel router

  1. Power on the travel router and wait for it to finish starting.
  2. Connect the router to the demo computer with Ethernet.
  3. Open a terminal and copy the complete command below.
Launch travel-router mode 
source /home/yihan/miniconda3/etc/profile.d/conda.sh
conda activate phystwin
cd /home/yihan/Research/Boba-Phone-Demo

bash scripts/run_demo2.sh \
  --case_name double_stretch_sloth \
  --batch_size 100 \
  --batch_grid_cols 10 \
  --batch_image_resolution 640x480 \
  --host 0.0.0.0 \
  --port 7860 \
  --qr_size 320 \
  --travel_router

The backslashes shown at line ends only make the command readable on screen. The Copy button removes them and produces clean terminal input.

Mode 2: Cloudflare

Attendee phones stay on conference Wi-Fi or cellular data. Keep both terminals below open throughout the demo.

Terminal 1: Create the public address

Start Cloudflare tunnel 
cloudflared tunnel --url http://127.0.0.1:7860

Cloudflare prints a box like this:

Example terminal output 
2026-09-02T13:53:52Z INF +--------------------------------------------------------------------------------------------+
2026-09-02T13:53:52Z INF |  Your quick Tunnel has been created! Visit it at (it may take some time to be reachable):  |
2026-09-02T13:53:52Z INF |  https://attending-graduated-streams-distributors.trycloudflare.com                         |
2026-09-02T13:53:52Z INF +--------------------------------------------------------------------------------------------+
Copy only the complete address beginning with https:// and ending with .trycloudflare.com. Its words change every time. Precheck messages followed by silence are normal.

Terminal 2: Start the phone demo

Paste only the generated address from Terminal 1 into this field. The page inserts it into the command automatically.

Paste a valid trycloudflare.com address to enable the copy button.

Launch Cloudflare mode 
source /home/yihan/miniconda3/etc/profile.d/conda.sh
conda activate phystwin
cd /home/yihan/Research/Boba-Phone-Demo

DEMO_PUBLIC_URL='https://PASTE-THE-GENERATED-URL.trycloudflare.com'

bash scripts/run_demo2.sh \
  --case_name double_stretch_sloth \
  --batch_size 100 \
  --batch_grid_cols 10 \
  --batch_image_resolution 640x480 \
  --host 127.0.0.1 \
  --port 7860 \
  --qr_size 320 \
  --public_url "$DEMO_PUBLIC_URL"

The Copy button removes the displayed line-ending backslashes before placing this command on the clipboard.

Stop the demo

Travel-router mode Press Ctrl+C in the demo terminal.
Cloudflare mode Press Ctrl+C in Terminal 2, then in Terminal 1.

Quick troubleshooting

The phystwin environment is not active

Copy these two commands, then retry the launch command.

Activate environment 
source /home/yihan/miniconda3/etc/profile.d/conda.sh
conda activate phystwin
Emacs does not appear immediately

Wait several seconds. Confirm that the router has power and Ethernet. If necessary, join manually using Emacs and password 315810612.

A phone cannot join Emacs

Disconnect the phone from its current Wi-Fi, wait until Emacs appears, and scan the Wi-Fi QR again.

The travel-router controller page does not open

Confirm that the phone is on Emacs. The terminal's [Demo2] Phone URL should normally begin with http://192.168.0.

Check computer address 
ip -4 -brief address show enp0s31f6
The Cloudflare address is hard to find

Scroll upward in Terminal 1 and look for trycloudflare.com. If no address appears after about one minute, press Ctrl+C and retry.

Cloudflare shows Error 502

Terminal 1 can reach Cloudflare, but the local demo is unavailable. Confirm that Terminal 2 is running and both commands use port 7860, then reload the phone page.

Port 7860 is already in use

An older demo is probably running. Return to its terminal, press Ctrl+C, and run the selected mode again.
